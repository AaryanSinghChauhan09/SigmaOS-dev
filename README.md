# SigmaOS-Dev

Unified development tools for SigmaOS, providing toolchain helpers, shell configurations, agent CLI, quick shell runner, and workspace management in a monorepo structure.

## Components

- **toolchain** - Developer toolchain helpers
- **fish** - Fish config & plugins
- **agent-cli** - AI agent CLI interface
- **quickshell** - Quick shell command runner
- **workspace** - Workspace management

## Installation

```bash
cargo build --workspace
```

## Testing

```bash
cargo test --workspace
```
